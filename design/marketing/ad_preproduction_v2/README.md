This is the complete preproduction pack for a 15-second Instagram Reels/TikTok ad. The next pass records the actual game and builds the finished video.

Open [Ad_Preview.html](Ad_Preview.html) locally to play the **silent 15-second storyboard** and inspect the hook variants. It uses labeled test stills with timed transitions; it is not a rendered movie or evidence of cleaning speed.
