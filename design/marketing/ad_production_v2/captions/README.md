# Illustrated caption art

Four transparent 1080 × 1920 SVG overlays. All display lettering is outlined, with editable type masters in `editable_text/`. Palette and rounded die-cut forms follow the original illustrated storyboard. The design intentionally leaves the central cleaning action uncovered. Gold glints on the restored-rug overlay are decorative graphic art.

Regenerate with `tools/build_ad_caption_art.cjs` using the bundled Node runtime.
