# Illustrated three-tool artwork

1080 × 1920 portrait composition with three vertically stacked real-gameplay windows.

Windows: x 64, width 952, height 450; y 355, 841 and 1327; corner radius 38. Composite `background.png`, the three masked gameplay crops, then `overlay.png`. The tool label occupies approximately the first 90 pixels of each window; frame the real contact action below it. `header`, `frames`, `labels`, and individual labels are also exported independently for optional motion.

All display SVGs contain outlined lettering and native vector paths; no raster footage is embedded. Editable lettering masters are in `editable_text`. The icons follow the actual game tools: mint brush with ivory handle, mint handheld hose sprayer with ivory lance and gold outlet, coral squeegee with ivory handle. The small hose badge accurately identifies the max-level equipment being shown; it makes no statement about availability at the start.

The approved v2 endcard remains the recommended ending. The layout preview has labeled placeholders, not simulated footage. Regenerate with `tools/build_ad_tools_art.cjs`.
